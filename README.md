# Bearing Fault Diagnosis

This project contains the data, source code, notebooks, and generated outputs for bearing fault diagnosis experiments.

## Project Structure

- `data/raw/` - original raw datasets
- `data/processed/` - cleaned or transformed datasets
- `notebooks/` - exploratory and analysis notebooks
- `src/` - project source code
- `outputs/figures/` - saved plots and visualizations

## Setup

1. Create a Python environment.
2. Install dependencies from `requirements.txt`.
3. Start with notebooks in `notebooks/`.
